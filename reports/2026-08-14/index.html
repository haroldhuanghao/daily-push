建议行动：一周内完成江苏核电、总包/调试与数字化平台伙伴账户图谱，准备“调试证据链＋运维基线”两页方案；下一节点跟踪首次临界与并网。

02 · INSPECTION

二、智慧巡检最新动态

1 条场景实证

白龙基地将防造假落到现场核查、甄别与闭环处置

施工质检证据追溯账户机会

项目 / 采购方 / 当前阶段：国家核安全局 8 月 13 日披露，华南监督站与中电投广西核电组织白龙基地 27 支参建单位队伍开展防造假技能竞赛；理论覆盖法规、工程质量与造假识别，实操围绕土建/安装高频风险，考核隐患排查、造假甄别和问题闭环。这是监管与业主治理活动，不是招标、AI 上线或中标。

技术方案与市场价值：业务链已明确为“现场核查—证据采集—风险识别—问题处置—闭环留痕”。影像时间戳、人员/工序绑定、电子签点、异常提示、整改销号和审计导出可作为既有平台的补充模块。

是否属于主流方向：是。核电工程数字化的价值正在从展示看板转向可核验质量证据；AI 只能辅助标记可疑点，最终认定与质量放行必须由授权人员按规程完成。

建议切入点：以平台＋集成为主、视觉算法为辅，联合总包或既有智慧工地平台；一周内做白龙“防造假闭环证据包”演示脚本并约业主/参建方验证。
来源：国家核安全局，2026-08-13
03 · AI

三、AI 视觉与多模态技术进展

2 条工程更新

Ultralytics 8.4.119 修复无效框进入 BYTETracker

跟踪可靠性有条件适合核电立即验证

已确认事实：Ultralytics 于上海时间 8 月 14 日 03:37 发布 8.4.119。官方说明 BYTETracker 会在创建轨迹前过滤宽或高为零/负值的检测框，避免无效卡尔曼滤波状态；同时将检测导出 top-k 限制在可用 anchor 数量内，降低小输入尺寸导出失败。

核电应用价值：适合人员/机器人/异物视频跟踪和小画面多路视频接入，可降低异常框导致跟踪链污染或服务崩溃的风险；它不提升核电缺陷识别本身，也不能替代现场误漏报验证。

工程化限制：仍受遮挡、低照、镜面反光、摄像机抖动、跨镜 ID、数据漂移和国产推理后端算子差异影响；AGPL-3.0/商业许可边界需法务确认，安全相关告警必须人工复核。

跟进建议：立即用坏框、空帧、低照、遮挡和小输入五类回归集对现网版本与 8.4.119 做 A/B；只有轨迹稳定性、误报与资源占用均通过门槛才升级。
来源：Ultralytics GitHub Release，2026-08-14（上海时间）

Ultralytics 8.4.120 改进确定性训练与隔离环境导出

可复现训练离线交付持续跟踪

已确认事实：Ultralytics 于上海时间 8 月 14 日 06:38 发布 8.4.120，用基于 arange 的确定性 anchor 生成替代 CUDA 累加路径，并移除 TensorFlow/非 YOLO 导出依赖中的旧 NVIDIA 软件源，官方称可减少确定性训练警告及隔离/CPU 环境的 DNS 与安装问题。

核电应用价值：有条件适合核电离线训练复核、受限网络导出和版本审计；可复现构建是质量证据的一部分，但版本更新没有提供核电数据、国产芯片性能或安全分级证据。

工程化限制：需固定驱动、CUDA/框架、随机种子、预后处理和数据哈希；TensorFlow 导出改进不等同于昇腾、RKNN、海光 DCU 等国产后端等价，LLM 接口也不宜直接接入生产控制。

跟进建议：持续跟踪，不因版本号直接投产；先生成同数据同配置两次训练的权重哈希、指标差和导出产物对比报告，再决定纳入受控基线。
来源：Ultralytics GitHub Release，2026-08-14（上海时间）
04 · DOMESTIC STACK

四、国产硬件与边缘智能专项

无厂商强新增

4.1 国产 CPU 与服务器

最新动态：今日未核验到鲲鹏、海光、飞腾、龙芯、兆芯或申威面向核电智慧巡检的新增产品/订单。

部署结论：中心平台以鲲鹏/openEuler 或海光/银河麒麟作主力/备选双线；仍须 PoC 后采用。

4.2 国产 GPU / NPU 与 AI 加速

最新动态：今日未见核电场景新实测。昇腾适合中心推理与较大视觉模型，RKNN 类 NPU 适合低功耗边缘视觉；大模型/RAG 先在中心隔离区验证。

部署结论：均为 PoC 后采用，不以框架“支持导出”替代国产后端黄金样本验收。

4.3 国产边缘算力设备

最新动态：无高价值新增。产品采购应继续要求宽温、掉电恢复、双网隔离、视频并发、签名升级与可回滚。

部署结论：工业边缘盒用于非安全级辅助巡检；未完成 EMC、连续运行和故障注入前不进生产。

4.4 国产操作系统与基础软件

最新动态：今日未见直接影响核电交付的新版本或兼容认证。银河麒麟/openEuler 维持主力与备选组合。

部署结论：建议 PoC 后采用；固定内核、容器运行时、驱动和安全补丁基线。

4.5 对智慧核电的部署建议

产品价值与部署层级：视觉边缘推理继续采用“国产 ARM/低功耗 NPU＋国产 OS＋离线容器”；厂级 AI 平台采用“鲲鹏/海光服务器＋昇腾/海光 DCU 可插拔加速＋openEuler/银河麒麟”；RAG / AI Agent 只读接入文档、台账、告警和工单副本，不直接控制安全级系统。

今日国产化部署结论：视觉边缘推荐 RK3588/RKNN 类方案作低功耗主线、昇腾边缘卡作多路/复杂模型备选；厂级平台优先鲲鹏＋昇腾，海光＋DCU 作第二路线；立即用同一黄金样本对 ONNX/CPU、昇腾和 RKNN 跑精度、延迟、功耗、重启恢复与 72 小时稳定性 PoC。规避单一模型格式、私有算子、厂商云运维和不可导出日志四类锁定。

跨平台能力优先级：第一优先建设统一预后处理、后端适配器、算子差异清单、离线安装包、SBOM、签名升级、回滚和自动回归；第二优先建设远程诊断但现场可完全离线的运维工具。

09 · INSIGHT

九、今日技术洞察

1. 未来 1—3 年最大的商业机会

结论：不是单一识别模型，而是覆盖建设、调试和运维的“边缘采集＋视觉/机器人辅助判断＋设备履历＋整改销号＋审计证据”闭环。

依据：田湾装料打开调试/运维基线窗口，白龙防造假明确现场闭环，科技兴安解读又将 PHM、边缘/孪生、应急 Agent 和机器人连成产品栈。

建议动作：把调试证据链、防造假质检和极端天气分别做成可验收场景包，而非继续增加泛化算法清单。

2. 值得立即投入验证的技术

结论：无效框过滤、跟踪故障注入、确定性训练、隔离环境导出和国产双后端等价回归。

依据：8.4.119/120 直接处理运行异常和可复现交付，而非只提高公开数据集分数。

建议动作：今天冻结五类坏场景与 200—500 个黄金样本，形成自动回归门禁。

3. 可能形成长期竞争壁垒的方向

结论：核电场景数据契约、失效模式库、跨芯片回归数据、审计证据和现场运维知识比通用模型权重更难复制。

依据：开源模型更新频繁，但客户验收依赖长期可维护、可解释、可回滚和规程一致。

建议动作：每个 PoC 必须沉淀样本、版本、误差、人工处置与验收结果，并获得合规使用授权。

4. 国产软硬件发展的最大帮助

结论：满足离线、供货、自主运维和分层成本控制，让边缘视觉与厂级 Agent 能按风险域部署。

依据：国产 CPU/NPU/OS 已具备基础覆盖，但框架层修复不能证明国产后端精度与稳定性。

建议动作：以同一黄金样本和同一验收门槛管理主力＋备选路线，不接受只给兼容证书不给复现报告。

5. 公司应优先建立的国产化能力

结论：统一预后处理、可插拔推理后端、离线包、SBOM、签名升级/回滚、审计日志、自动回归和现场故障定位。

依据：这些能力可跨芯片、模型和操作系统复用，把一次性适配变为可销售的持续交付资产。

建议动作：设一名兼容矩阵负责人；所有厂商合作必须交付构建清单、黄金样本结果和故障恢复报告。
