田湾7号机组首次装料监督覆盖先决条件、关键工序和后续带核调试

带核调试全过程监督安全关键节点

已确认事实：国家核安全局于 8 月 25 日披露，田湾核电站7号机组首次装料已启动，机组转入带核运行调试阶段。装料前，监管人员逐项核验组织与人员准备、运行许可证文件批复和相关系统设备准备；装料期间全程监督燃料组件起吊、场内转运、堆芯装入与精准就位；后续还将跟进首次临界、功率提升及各类调试试验。公开信息未宣布新的 AI、数字孪生或智慧巡检系统采购、上线。

判断：从建造转向带核调试后，数字化产品的首要价值不是替代授权人员判断，而是把先决条件、操作步骤、设备状态、人员资质、异常处置和签批记录串成可审查证据链；任何视觉识别只应形成提示和带时间戳的候选证据。

建议行动：以“装料先决条件包”和“关键动作证据包”各做一套脱敏演示，明确数据来源、版本、责任人、复核人、变更原因和导出格式；先在非生产数据上验证完整性与追溯，再讨论现场接入。

03 · AI

三、AI 视觉与多模态技术进展

最多 2–3 条

Ultralytics 8.4.129 增加 BF16 训练，并优化 LiteRT GPU 委派与多数据集调参

BF16LiteRT GPU多数据集须独立回归

已确认事实：Ultralytics 于 8 月 25 日发布 v8.4.129：训练参数 amp 新增 BF16；多数据集调参交由 MultiTrainer 隔离执行并记录逐数据集与宏平均指标；YOLO26 端到端 LiteRT 导出调整检测头算子，以减少 GPU 委派时回退 CPU；常规批量图像解码和部分 FastSAM 预处理也增加并行路径。官方说明并未给出核电数据、国产 NPU 或现场长稳结果。

核电应用价值：BF16 更适合在支持的 CUDA 训练设备上验证小目标、低照、反光和类别不平衡数据的数值稳定性；多数据集指标有利于避免“一个厂区平均分掩盖另一个厂区退化”。LiteRT GPU 变化可用于 Android/轻量边缘终端的非安全级检测验证，但不能外推到昇腾、RKNN 或其他国产 NPU。

工程化限制：需固定模型、数据版本、随机种子、预后处理和阈值，比较 FP32/FP16/BF16 的逐场景召回、误报、收敛、显存与复现性；LiteRT 必须核对委派比例、CPU 回退、热稳定、功耗、空目标和小目标精度。所有告警继续由人员按规程复核。

跟进建议：立即做隔离验证，暂不升级生产。冻结 v8.4.128 与 v8.4.129，先跑离线精度与导出一致性，再做 72 小时同负载长稳；任何生产变更都要保留回滚包和版本化验证报告。
来源：Ultralytics GitHub Release｜v8.4.129（2026-08-25）
04 · DOMESTIC STACK

四、国产硬件与边缘智能专项

最多 3–5 条

4.1 国产 CPU 与服务器

今日无高价值新增。继续把数据库、证据归档、只读检索和审计导出作为中心侧主负载；采购前用真实并发、国密、备份恢复和长期支持版本验证，不仅看单项算力。

4.2 国产 GPU / NPU 与 AI 加速

今日无可核验的新核电项目级进展。Ultralytics 的 LiteRT/CUDA 结论不能转写为国产 NPU 兼容；昇腾、寒武纪、RKNN 等必须分别锁定算子、量化、精度和驱动矩阵。

4.3 国产边缘算力设备

主力仍是低功耗盒式设备承载视频接入、缓存、推理与健康监测；PoC 必测断网续传、时钟漂移、硬件看门狗、温升降频、掉电恢复和 72 小时长稳。

4.4 国产操作系统与基础软件

优先验证麒麟/统信与容器运行时、视频编解码、NPU 驱动、离线升级、SBOM 和审计日志组合；机器人/终端侧只部署签名模型与最小权限服务。

4.5 对智慧核电的部署建议

今日国产化部署结论：视觉边缘推理以“国产 NPU 盒式设备 + 本地缓存 + 人工复核”为主力；厂级证据与知识平台以国产 CPU 服务器和本地对象存储为主力；RAG/AI Agent 仅以只读检索、缺项提示和差异比对进入 PoC。外部云推理、自动写控制参数和自动关闭质量问题暂不进入生产。

适配结论：国产主力方案须经逐模型、逐算子、逐驱动 PoC 后采用；x86/CUDA 可作为研发和精度对照备选，不作为国产适配已完成的证据。

五、工业数据治理与数字孪生趋势

带核调试证据底座应围绕“条件—动作—结果—复核”建模

已落地证据：国家核安全局公开信息明确了装料前组织、人员、许可文件和系统设备准备核验，以及装料中起吊、转运、装入、就位等关键工序监督；但没有宣布新的数据平台、数字孪生或 AI Agent 上线。

判断：可商业化的最小产品不是一张“进度大屏”，而是每个先决条件和关键动作的版本化证据对象：对象 ID、原始来源、采集时间、设备/人员、规程版本、复核结论、异常与变更链。数字孪生只承担对象定位与关系导航，只读 Agent 只做权限内检索和缺项提醒。

建议行动：用 30 条脱敏样例建立字段字典、证据哈希、电子签批、权限继承和审计导出；以“任一结论能在两分钟内回到原始证据”为验收门槛。

09 · INSIGHT

九、今日技术洞察

一至三年机会在“可审查证据操作系统”，不是更大的模型

结论：最大商业机会是把现场感知、规程、对象编码、人员资质、版本、异常与签批串成连续证据；立即验证的是证据完整性、跨系统追溯、模型版本可复现和断网可恢复。长期壁垒来自核电对象/规程语义、审计历史、现场接口与国产软硬件兼容矩阵，而不是单个通用模型。

依据：田湾装料监督公开信息把先决条件、关键动作和后续调试串成全过程监管链；Ultralytics v8.4.129 同时提醒团队，训练精度和导出执行路径会随版本改变，模型结果必须与版本、数据和硬件绑定保存。

建议动作：由产品、核电业务、数据平台与算法四方共同冻结证据对象 v0.1；算法团队提交 v8.4.128/129 可复现实验包，平台团队验证任一告警到原始帧、模型、阈值和人工结论的反向追溯。
