3 条

v8.4.138 修复旧检查点、YOLO-World 与 channels-last 组合故障

上海时间 9 月 2 日 07:01工业视觉兼容性修复

已确认事实：Ultralytics 于 9 月 1 日 23:01 UTC 发布 v8.4.138：恢复 8.4.95 之前旧检查点相关类的受限加载与 YOLO-World 加载；以 reshape 修复 MuSGD 在 channels-last 非连续梯度下崩溃；SAM/SAM2/SAM3 特征提取改用推理模式；同时修复空目标批次的 DDP 梯度、分布式调参失败数据集记录，并明确不同导出后端下 quantize 不代表统一精度。

判断：相较昨日 v8.4.137，这是对默认 channels-last 变更的直接稳定性补丁，也说明“能加载、能跑、量化参数相同”不足以证明跨版本和跨后端等价。核电视觉应把旧资产兼容、空目标工况、内存布局和真实计算精度纳入升级闸门。

建议行动：冻结 8.4.137/138 双基线，使用旧检查点、YOLO-World、空目标批次、SAM 连续推理和目标国产后端各跑一组回归；记录模型哈希、布局、实际精度、峰值内存、误漏报与人工复核结果。

来源：Ultralytics GitHub Release｜v8.4.138

03 · AI

三、AI 视觉与多模态技术进展

2 条

SAM 推理模式优化适合验证长时交互分割，不构成现场性能保证

核心能力与核电场景：v8.4.138 将 SAM、SAM2、SAM3 图像嵌入计算放入推理模式，避免重复推理保留不必要的自动求导图。它适合离线缺陷轮廓标注、人员辅助复核和工单证据整理的内存稳定性验证。

工程化限制：官方未提供核电缺陷数据、边缘设备功耗、长稳、辐射/粉尘/反光条件或误漏报结果；内存下降不代表分割准确率、提示一致性和审查可解释性达标。

跟进建议：立即做隔离验证。对同一图像连续提取 1000 次嵌入，记录峰值内存、时延、输出哈希与人工修订量；只用于辅助标注和复核，不自动放行。
来源：Ultralytics v8.4.138

量化参数需升级为“后端实际精度”证据

核心能力与核电场景：v8.4.138 文档澄清 quantize 在不同导出格式中可能选择或请求不同运行时精度。对表计、异物、渗漏和人员行为识别，这要求将“配置值”与“部署后端实际执行”分开记录。

工程化限制：国产 NPU 的算子回退、混合精度、校准集、预处理和 NMS 可能改变精度、时延与功耗；通用文档不能替代设备侧 profiler、输出对齐和独立黄金集。

跟进建议：生产暂不随版本升级。为 ONNX、客户指定国产 NPU 和 CPU 备选分别导出，保存图优化日志、算子精度/回退清单和逐样本差异；人工审批版本晋级。
来源：Ultralytics v8.4.138
04 · DOMESTIC STACK

四、国产硬件与边缘智能专项

4 项结论

4.1 国产 CPU 与服务器

今日无新产品级证据。中心平台继续以客户指定国产 CPU 为主力，要求模型资产、事件图谱、规则和审计日志离线可用；不把 v8.4.138 的分类预处理优化外推为国产 CPU 收益。

4.2 国产 GPU / NPU 与 AI 加速

PoC 后采用。对客户指定国产 NPU 逐后端核验量化实际精度、算子回退、输入解码和 NMS；CUDA channels-last 与 MuSGD 修复不是国产加速卡适配证据。

4.3 国产边缘算力设备

广东电网公告把数字终端到货安全抽检和配件整改写入采购链。机器人边缘设备需验证断网缓存、热降频、72 小时长稳、故障撤离、远程升级与回滚。

4.4 国产操作系统与基础软件

麒麟、统信或 openEuler 环境锁定 Python、推理 SDK、OpenCV、编解码、容器与驱动；保存 SBOM、漏洞处置、国产化测评和现场版本基线。

4.5 对智慧核电的部署建议

今日国产化部署结论：边缘视觉采用“客户指定国产 NPU＋本地缓存＋人工复核”，中心采用国产 CPU 服务器、离线事件图谱与不可变证据存储；RAG/AI Agent 只做权限内检索、证据编排和缺项提示。

适配结论：国产 CPU 中心平台为主力；客户指定国产 NPU 为 PoC 后边缘主力，国产 CPU 推理为备选；v8.4.138 只进入隔离验证环境，未通过旧模型、量化、空目标、72 小时长稳、网络隔离和回滚验证前暂不进生产。
