# 《核电智慧巡检与工业智能化行业日报》编辑规范

## 目标与边界

日报服务于核电智慧巡检、工业视觉 AI、边缘智能、工业数据治理、数字孪生、工业 AI Agent，以及国产 CPU/GPU/NPU、操作系统与信创交付。它的目标是识别已经或即将形成订单、产品能力或竞争壁垒的事实，不是罗列泛行业新闻。

所有来源优先采用监管机构、招投标公告、企业官网、论文原文和开源项目官方仓库。未能确认的信息必须标为“待核实”；不得杜撰项目、金额、性能、客户或论文结论。核安全、生产控制、网络安全相关内容始终坚持“AI 辅助决策、人机协同、人工复核、规程优先”。

## 信息准入与写法

主体内容只收录至少符合一项的事项：有明确项目、采购、招标、中标、上线或试点；有实质政策、标准、监管或安全变化；有可验证的技术发布或开源更新；直接影响产品、市场、交付或国产化适配；或具有明确的一至三年商业价值。

每一条必须清晰写出以下三部分：

1. **已确认事实**：带发布日期和可点击来源。
2. **判断**：仅基于事实的推断，说明影响对象和具体原因。
3. **建议行动**：可执行的下一步，避免“值得关注”“前景广阔”等空泛表述。

技术类条目还必须说明：是否适合核电、具体适用场景、工程化限制（数据、误漏报、现场环境、算力功耗、网络隔离、可解释性和审查）以及投入建议（立即验证／持续跟踪／暂不投入）。国产化条目必须给出主力、备选、PoC 后采用或暂不进生产的结论。

## 去重与持续跟踪

- 首次报道完整说明背景、影响和行动；后续只在审批、开工、并网、采购、招标、中标、上线、扩容、政策变化或实测突破等实质进展出现时更新，并说明相较前次新增的内容。
- 没有实质变化的事项不得再次进入主体，只能在“持续跟踪事项”中用一行记录状态、今日是否新增和下一观察节点。
- 单期坚持少而精：重大事件 3–5 条、智慧巡检 3 条、AI 视觉 2–3 条、国产化 3–5 条、竞争动态 3 条、商业机会 1–5 个。
- 若当天没有高价值新增，必须直说，并把篇幅用于仍需推进的存量商机、客户动作或技术验证任务。

## 必需栏目

每期页面按以下顺序组织；没有合格信息的栏目可简写为“今日无高价值新增”，但不能以低价值内容凑数：

1. 今日一句话结论（不超过 50 字，明确管理层当天动作）
2. 今日重大行业事件
3. 智慧巡检最新动态
4. AI 视觉与多模态技术进展
5. 国产硬件与边缘智能专项（CPU/服务器、GPU/NPU、边缘设备、操作系统、部署建议与当日结论）
6. 工业数据治理与数字孪生趋势
7. 竞争对手动态
8. 商业机会
9. 持续跟踪事项
10. 今日技术洞察（1–3 年机会、验证重点、壁垒、国产化价值、能力建设）
11. 给公司的建议（当天不超过 3 条；并列出 1–3 个月与 6–24 个月计划）

## 随附交付物

- `cover.png`：1200×628 PNG，深蓝、青蓝、灰白为主，少量橙色强调；可使用抽象核电站、工业管线、数字网格、芯片或巡检节点，但不虚构厂区、客户或 Logo。标题、日期和当天战略结论在手机缩略图中清晰可读。
- `wecom-summary.md`：以 `【核电智慧巡检与工业智能化行业日报｜YYYY-MM-DD】` 起始，给出不重复正文的三条“今日新增判断”、两条建议动作和当天永久链接。无高价值新增时如实说明。

封面、群摘要与 HTML 的核心结论必须一致。所有链接都必须指向当天的 `/reports/YYYY-MM-DD/` 永久地址。
